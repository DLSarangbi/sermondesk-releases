# SermonDesk releases

Installers for [SermonDesk](https://sarangbi.co), a local-first sermon manager. Nothing here but built installers and the files the app's auto-update reads; the source lives in a private repository.

**Download for Windows:** [SermonDesk-Setup.exe](https://github.com/DLSarangbi/sermondesk-releases/releases/latest/download/SermonDesk-Setup.exe) is always the newest installer. Each release also lists the same file under its version number.

Windows builds are unsigned until the first revenue buys a certificate, so Windows shows a SmartScreen warning on first run: click **More info**, then **Run anyway**. Once installed, the app checks for updates itself and offers each new version.
